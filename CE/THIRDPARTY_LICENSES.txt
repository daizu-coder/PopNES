Shinonome bitmap font (16dot)
------------------------------
Upstream: https://github.com/code4fukui/shinonome-font
(a GitHub mirror of the original /efont/ "Shinonome" font archive)

Main design (16dot): Yasuyuki Furukawa <Furukawa.Yasuyuki@fujixerox.co.jp>
  http://www.on.cs.keio.ac.jp/~yasu/
A small number of symbol glyphs are reused as-is from the X11 standard
"jiskan16" font (see the upstream project's AUTHORS file for the exact
character list).
Maintained by: The Electronic Font Open Laboratory (/efont/)
  http://openlab.ring.gr.jp/efont/

The upstream README.md mentions the MIT License; the LICENSE file it
links to contains the following declaration (Japanese original,
reproduced verbatim, with an English paraphrase below):

Galmuri font (Galmuri14, GalmuriMono11)
---------------------------------------
Upstream: https://github.com/quiple/galmuri
Version used: 2.40.4 (commit 71e1cac)
Copyright (c) 2019-2025 Lee Minseo (quiple@quiple.dev)
License: SIL Open Font License, Version 1.1 (full text below)

PopNES embeds glyph data for its Japanese/English menu text. The default
build (make, CE_FONT=galmuri14) uses glyphs converted from Galmuri14;
the characters Galmuri14 does not have (Greek, Cyrillic and some math
symbols) are filled in from the Shinonome 16dot font described above.

The glyph bitmaps of dist/Galmuri14.bdf (and, for the optional
CE_FONT=galmuri11 build, dist/GalmuriMono11.bdf) were converted by the
sister PopPCE project's CE/tools/galmuri2c.py into the C glyph tables
CE/ce_galmuri14.h and CE/ce_galmuri11.h (a Modified Version under the OFL: format
conversion, character subset, vertical placement, and missing glyphs
filled from Shinonome 16dot). No Reserved Font Name is declared after
the copyright statement in the upstream ofl.md. These glyph tables
remain under the SIL Open Font License 1.1; the rest of PopNES is not
covered by it.
